# QR Code Generator 🧾

A simple **QR Code Generator desktop application** built with **Python and Tkinter**.
The application allows users to enter text or a URL, generate a QR code, preview it, and save it as an image.

## Features

*  Simple graphical user interface
*  Generate QR codes from text or URLs
*  Preview the generated QR code
*  Save QR codes as PNG or JPG images
*  Clear the input and generated QR code
*  Input validation and error messages
*  Built entirely with Python

## 🛠️ Technologies Used

* **Python**
* **Tkinter** – GUI development
* **qrcode** – QR code generation
* **Pillow (PIL)** – Image processing and Tkinter image support

##  Installation

### 1. Clone the repository

```bash
git clone https://github.com/your-username/QR-Code-Generator.git
```

### 2. Open the project folder

```bash
cd QR-Code-Generator
```

### 3. Install the required libraries

```bash
pip install -r requirements.txt
```

Or install them manually:

```bash
pip install qrcode[pil]
```

## ▶️ How to Run

Run the following command:

```bash
python qr_generator.py
```

The application window will open.

1. Enter a **URL or text**.
2. Click **Generate QR Code**.
3. Preview the QR code.
4. Click **Save QR Code**.
5. Choose the location and filename.
6. Your QR code will be saved as an image.
